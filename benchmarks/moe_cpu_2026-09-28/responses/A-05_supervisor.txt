## 1) Analyse

**Anforderungskomponenten:**
- PDF-Upload-Funktionalität
- OCR/Vision zur Textextraktion
- Speicherung als Knowledge-Eintrag
- Integration in Chat-System

**Technische Einschränkungen:**
- Lokaler Stack: Open WebUI, Qwen Code, local-tools MCP, Ollama
- Keine Cloud-Abhängigkeiten
- Keine externen Tools/Services

**Architektur-Design:**
- PDF-Verarbeitung lokal mit PyPDF2 oder pdfplumber
- OCR durch Tesseract (via local-tools MCP)
- Knowledge-Store: lokaler Vector DB (z.B. ChromaDB)
- Integration über Open WebUI API

**Risiken:**
- OCR-Qualität auf lokalem Setup
- Performance bei PDF-Verarbeitung
- Lokale Ressourcen (Speicher, CPU)
